# ARDENT — premium sneaker banner (1200×628)

- `ardent-banner-1200x628.svg` — vector master. Open it in Adobe Illustrator (File → Open). All text is converted to outlines, so you don't need any fonts installed.
- `ardent-banner-1200x628-preview.png` — PNG preview.
- `make_banner.py` — generator script. To regenerate: `pip install fonttools`, put `Bebas.ttf` (Bebas Neue) and `Montserrat.ttf` (Montserrat variable) in a folder, then run
  `python3 make_banner.py <fonts-dir> ardent-banner-1200x628.svg`.

Fonts: Bebas Neue and Montserrat (SIL Open Font License), both from Google Fonts.
The brand name, logo mark and shoe artwork were made up for this banner.
